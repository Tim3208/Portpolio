# 이전 AGENTS.md 절 번호 참조표

기존 AGENTS.md의 콘텐츠·디자인·작업 지침을 주제별 문서로 분리했다. 소스 주석에 남아 있는 `AGENTS.md §번호` 또는 문맥상 같은 문서를 가리키는 `§번호`는 아래 새 위치를 따른다. 새 주석과 문서는 의미 있는 앵커를 직접 참조한다.

원문의 사실과 계약은 연결된 문서에 통합했다. 중복 예시와 초기 구현 순서는 현재 구조에 맞춰 정리했다. `globals.css §7`처럼 다른 파일을 명시한 번호는 이 표의 대상이 아니다.
